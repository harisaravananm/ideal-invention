# ideal-invention
☁️ AWS VPC Peering Project: Connects `ewb-vpc-a` (`10.10.0.0/16`) and `ewb-vpc-b` (`10.20.0.0/16`) via `ewb-a-b-peer` in Sydney (`ap-southeast-2`). Demonstrates secure private cross-VPC communication using custom route tables, least-privilege security groups, and EC2 verification.
